# Scripts for GenBank submissions

This project has custom scripts that convert sequence names to a GenBank-ready 
format in three different file types: GFF (exported from Geneious), FASTA (exported from Geneious), TSV/Excel (user's annotations),
and prepares files as input for *table2asn*.

This follows the approach used in [Mark Stenglein's workflow](https://github.com/stenglein-lab/Helpful_code_snippets/tree/main/create_files_for_genbank_submission), but too much customization was required to make use of his scripts.

### Requirements

* Python
    * biopython (for seqio)
    * pandas
* [table2asn](https://www.ncbi.nlm.nih.gov/genbank/table2asn/)

### Key
* User files - data provided from Geneious and Tillie/Mollie's Spreadsheet tracking their sequences
  * sequences (FASTA) and CDS annotations (GFF) from Geneious
  * Excel Spreadsheet or TSV
* Main scripts - apply functions to make GenBank-allowable seqIDs and annotations
* Submission files
  * tbl - Five-column tab delimited format
  * fsa - Multi fasta file with the seqIDs "fixed" and the modifiers added
  * sqn - Generated by `table2asn`
* Extra files
  * a "valid" TSV tracking the operations of the main scripts
  * `table2asn` generates: gbk (example Genbank file) and val (errors and warnings)

### Differences between Tillie and Mollie

Although the workflow is the same, there were different individual formatting challenges. Those are encapsulated in each student's
data model: Tillie.py or Mollie.py. *They do not share a common Genbank module (would be good for future submissions)*.
